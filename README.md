# AI SEO Advisor

Check pages for issues such as missing descriptions, weak heading structure, and images without alt text. Editors can also request AI suggestions and review their saved reports.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and AI and Entity Plus. Configure a chat model for AI suggestions. Local checks can run without a configured model.

## Installation

1. Install and enable the module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI SEO Advisor** at `admin/config/ai/ai-seo`, enable the desired content types, and grant report permissions.

See the [module wiki](https://github.com/backdrop-contrib/ai_seo_advisor/wiki) for setup, use, and troubleshooting.
