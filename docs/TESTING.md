## Manual Testing Steps

### Step 1: Configure the Module
1. Go to **admin/config/ai/seo**
2. Enable on at least one content type (e.g., Page, Post)
3. Configure thresholds and checks
4. Optionally enable AEO checks
5. Save configuration

### Step 2: Create/Edit Content
1. Go to **node/add/page** (or edit existing page)
2. Add some content with title, body, etc.
3. Scroll to "SEO Analysis" fieldset
4. Enter an optional focus keyword
5. Click "Analyze SEO" button

**Expected Results:**
- AJAX request completes
- Report displays in the panel
- Score and status shown (0-100, RED/AMBER/GREEN)
- Checks listed with pass/fail icons
- Message: "SEO analysis saved. View all reports"

### Step 3: View Report History
1. Save the node if not already saved
2. Go to the node view page
3. Look for **"SEO" tab** in local tasks
4. Click the SEO tab

**Expected Results:**
- Table of reports displayed
- Columns: Date, Score, Status, Focus Keyword, Generated By, Operations
- Each report has a "View" link

### Step 4: View Individual Report
1. From the report list, click "View" on any report
2. Should go to `node/{nid}/seo/{report_id}`

**Expected Results:**
- Full report displayed
- Metadata section shows: Created date, User, Focus keyword
- Same report rendering as on edit form
- Breadcrumb: Home > Node Title > SEO Reports > Current Report

### Step 5: Generate Multiple Reports
1. Edit the node again
2. Change the focus keyword or content
3. Click "Analyze SEO" again
4. View the SEO tab

**Expected Results:**
- Multiple reports in the list
- Newest report at the top
- Each with different timestamp
- Can compare scores over time

### Step 6: Test Permissions
1. Create a user with only "view ai seo reports" permission
2. Login as that user
3. Try to view a node with reports

**Expected Results:**
- SEO tab is visible
- Can view report list and individual reports
- Cannot see "Analyze SEO" on edit form (no edit access)

## Database Queries for Testing

### Check reports were created
```sql
SELECT report_id, entity_id, title, score, status, FROM_UNIXTIME(created) as created_date
FROM ai_seo_report
ORDER BY created DESC
LIMIT 10;
```

### Check reports for specific node
```sql
SELECT report_id, title, score, status, focus_keyword, FROM_UNIXTIME(created) as created_date
FROM ai_seo_report
WHERE entity_type = 'node' AND entity_id = 1
ORDER BY created DESC;
```

### Check report data structure
```sql
SELECT report_id, LENGTH(report_data) as data_size, LENGTH(html_snapshot) as html_size
FROM ai_seo_report
LIMIT 5;
```

## Troubleshooting

### Issue: SEO tab not appearing
**Check:**
1. Is content type enabled in module settings?
2. Does user have permission to view reports?
3. Clear menu cache: `ddev bee cc menu`

### Issue: Reports not saving
**Check:**
1. Is Entity Plus module enabled?
2. Does ai_seo_report table exist?
3. Check watchdog: Look for errors
4. Verify entity classes are loading

### Issue: Entity class errors
**Check:**
1. Autoload info is registered
2. File exists: `includes/ai_seo_report.entity.inc`
3. Clear registry cache: `ddev bee cc all`

### Issue: AJAX not working on edit form
**Check:**
1. JavaScript console for errors
2. Check if the AI module is enabled
3. Verify API key is configured
4. Check form is on an enabled content type

## API Usage Examples

### Create a report programmatically
```php
$report = entity_create('ai_seo_report', array(
  'entity_type' => 'node',
  'entity_id' => $node->nid,
  'report_type' => 'seo_analysis',
  'title' => $node->title,
  'focus_keyword' => 'example keyword',
  'score' => 85,
  'status' => 'GREEN',
  'report_data' => $analysis_results,
  'html_snapshot' => $rendered_html,
));
$report->save();
```

### Load reports for a node
```php
$query = db_select('ai_seo_report', 'r')
  ->fields('r')
  ->condition('entity_type', 'node')
  ->condition('entity_id', $nid)
  ->orderBy('created', 'DESC');
$results = $query->execute();

foreach ($results as $row) {
  $report = entity_load('ai_seo_report', $row->report_id);
  // Work with $report object
}
```

### Get latest report
```php
$result = db_select('ai_seo_report', 'r')
  ->fields('r', array('report_id'))
  ->condition('entity_type', 'node')
  ->condition('entity_id', $nid)
  ->orderBy('created', 'DESC')
  ->range(0, 1)
  ->execute()
  ->fetchField();

if ($result) {
  $latest_report = entity_load('ai_seo_report', $result);
}
```
